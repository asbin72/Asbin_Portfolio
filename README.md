# Asbin T S — Portfolio

A modern, high-performance portfolio website built with React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, and GSAP.

## 🚀 Features

- **Cyber/Brutalist Technical Aesthetic**: Dark background, high-contrast neon accents (`#C8FF00`), monospace typography, and interactive canvas particle network.
- **Interactive Components**: Magnetic CTA buttons, dynamic section tracking, animated project showcase, and custom smooth interactions.
- **Resume Integration**: Embedded direct access to view and download resume PDF.
- **Fully Responsive**: Optimized layouts for mobile, tablet, and ultra-wide displays.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS
- **Animations**: Framer Motion, GSAP, Canvas 2D API
- **Icons**: Lucide React
- **Build Tool**: Vite

## 📦 Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
