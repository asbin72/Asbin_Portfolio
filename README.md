## 📌 About

A modern, high-performance portfolio website built with **React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, and GSAP** — designed around a cyber/brutalist technical aesthetic.

This site brings my projects, skills, and development journey together in one place, with a dark neon-accented interface and interactive, animated components rather than a static one-page resume.

---

## 📂 What's Inside

| Section | Description |
| --- | --- |
| Hero / Introduction | A personal introduction with an animated canvas particle network background |
| Featured Projects | An animated showcase of my selected project work |
| Tech Stack | Languages, frameworks, and tools I build with |
| Resume | Embedded viewer with direct download of my resume PDF |
| Contact | Ways to reach me and links to my profiles |

---

## 🚀 Features

- **Cyber/Brutalist Technical Aesthetic** — dark background, high-contrast neon accents (`#C8FF00`), monospace typography, and an interactive canvas particle network.
- **Interactive Components** — magnetic CTA buttons, dynamic section tracking, animated project showcase, and custom smooth interactions.
- **Resume Integration** — embedded direct access to view and download my resume PDF.
- **Fully Responsive** — optimized layouts for mobile, tablet, and ultra-wide displays.

## 📦 Getting Started

**Installation**
```bash
npm install
```

**Development Server**
```bash
npm run dev
```

**Build for Production**
```bash
npm run build
```
